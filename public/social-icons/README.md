# Social icon assets

PNG variants are generated from the SVG files alongside them, sourced from the Simple Icons project (https://github.com/simple-icons/simple-icons). The bundled license is CC0-1.0. LinkedIn uses the project's 13.0.0 icon; other SVGs were retrieved from its develop branch on 2026-11-01. Each SVG contains the exact source path used for the PNG variants.

Brand names and logos remain trademarks of their respective owners. Check each platform's brand guidelines for use. These assets identify links to those platforms; they do not imply endorsement.

Files ending in `-v1.png` are immutable because delivered emails may reference them. Add a new version rather than replacing or deleting an old file. User-uploaded custom icons are kept in configured persistent image storage, not this source directory.
